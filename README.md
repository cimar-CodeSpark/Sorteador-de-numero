# 🎲 Sorteador de Números

Um aplicativo simples e interativo para **sortear números aleatórios** dentro de um intervalo definido pelo usuário.  
Construído com **HTML, CSS e JavaScript**, o projeto possui uma interface moderna com efeitos visuais e utiliza a biblioteca [SweetAlert2](https://sweetalert2.github.io/) para exibir mensagens estilizadas.

---

## 🚀 Funcionalidades
- Definir um número **mínimo** e **máximo** para o sorteio.
- Escolher a **quantidade de sorteios**. (em construção)
- Exibir o resultado com **alertas animados**.
- Interface responsiva com **efeito neon** e fundo personalizado.
- Feedback visual com destaque para o número sorteado.

---

## ▶️ Como Usar
1. Defina os valores mínimo e máximo.
2. Escolha a quantidade de sorteios. (em construção)
3. Clique em "Sortear" e veja o resultado!

📸 Exemplo de Uso
Inserindo mínimo = 1 e máximo = 10, o sistema sorteará um número aleatório nesse intervalo.
O resultado será exibido com destaque em uma janela estilizada.
